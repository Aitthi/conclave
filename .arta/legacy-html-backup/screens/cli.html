Overview central system tool v1.0

ขับเคลื่อนทั้งระบบจากเทอร์มินัล — workspace, agent, การส่ง message เข้า input, blackboard และ snapshot ทุกอย่างที่ทำใน UI ทำผ่าน conclave ได้หมด

~/code/codeup
$ conclave agent ls
Atlas cli · running Iris chat · idle
$ conclave send @Iris "สรุปผล benchmark ให้ทีม"
→ injected into Iris input · auto-submitted ✓
$ conclave bb get bench/results
{ opus: 91.4, sonnet: 78.0, … }
$ conclave snapshot --agent Iris --label "before refactor"
saved · 22k tokens
Agent ก็เรียก conclave เป็น tool ได้

เป็น built-in tool กลาง ทุก agent ใช้ได้เลย — Maestro มอบงานด้วย conclave send @Atlas …, agent อ่าน/เขียน blackboard ด้วย conclave bb, หรือ snapshot ตัวเองด้วย conclave snapshot
