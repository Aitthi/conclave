## Settled product design
- Overview is app-global, not scoped to selected workspace. It is initial landing destination on normal launch and available through Conclave brand button at top of rail (real new brand mark, accessible label Overview). Selecting a workspace enters its existing workspace UI; Overview does not start/stop agents. Global libraries remain usable.
- Use full available area beside Rail; no misleading selected workspace roster beside the global overview. Preserve underlying agents/runtime; navigation has no launch/stop side effects.
- Header Overview, short functional explanation, visible New workspace action that invokes existing Link folder flow. Native restrained tool UI using committed theme tokens and typography, readable at 880x560, no marketing hero.
- Primary area: scannable workspace ROWS/table, not identical giant cards. Each row shows identity/name, folder path, Started/Stopped state (explicit label), agent activity (working count/total), open tasks, and tasks needing attention broken into Blocked/Review when present. Counts are product display semantics; researcher is verifying authoritative engine definitions. Do not invent spend/cost/percentages/last-active timestamps the engine cannot supply. Zero is not unknown; loading/error states distinct.
- Compact top summary may show active (nonarchived) workspace count, currently working agents, and blocked/review tasks. Keep units explicit, no giant metric cards. Search by workspace name/path and Active / Archived tab filters with counts. Active means NOT archived, includes stopped workspaces; explain this via copy or use Workspaces as first tab if clearer.
- Open workspace is row primary action. Overflow/manage actions keep archive away from accidental primary clicks. For stopped/non-running workspaces Archive is a reversible immediate action with undo/restore access; no extra confirmation modal required. Archive retains all agents, sessions/history, tasks, memory, artifacts and project files. Archived workspaces disappear from normal Rail and active list.
- Archive never silently stops active agents. Started workspace should explain Stop workspace before archiving and expose the existing Stop action/context where appropriate. Race/back-end refusal surfaces inline without hiding the workspace. Designer must not invent an auto-stop-and-archive flow.
- Archived tab: name/path, Archived label, Restore primary. Restore returns workspace to normal list in stopped state, does not launch agents, and remains on Archived list view with success feedback. Optional Open after restore is explicit. Permanent delete remains a separate clearly destructive action in existing settings; do not make archive a euphemism for delete. Exact archive eligibility may be refined by Aoki once research returns.
- Workspace settings/EditWorkspace gains Archive section/action above and visibly separated from permanent delete, with concise retention copy and eligibility reason.
- Empty states: no workspaces (Link folder CTA), no search results (clear search), no archived workspaces (brief explanation); all-archived state has Restore path. Error state has Retry, loading does not render fake zeros. Row mutations have local pending/disabled/error feedback. Keyboard/focus + light/dark native conventions required.
